Proofread supported text fields

Emails, tweets, forum posts, and blog editors can show squiggles in supported visible fields on pages where the extension has access, including supported frames. Non-empty visible fields are checked automatically unless you pause proofreading or disable the site.

Your prose stays local by default

The extension sends supported text to Lexicon on your own machine and does not store page text in extension storage. If you configure a remote AI or proofreading server, that server may receive the text sent to it. Your personal dictionary is shared with the desktop app through the same-device sidecar.

One-click fixes

Suggestion chips pop up over the flagged word with an Apply Fix button. No copying text back and forth.

Alt + Shift + L

Press the shortcut on a supported page to proofread the focused text field, or use the popup to run a manual check.

Install in Chrome
  1. Download the Chrome extension .zip from the button above (or GitHub Releases).
  2. Unzip it to a folder you will keep. Loaded unpacked extensions must stay on disk.
  3. Open chrome://extensions, enable Developer mode (top-right).
  4. Click Load unpacked and select the unzipped folder (open the inner zip folder if you see one).
  5. Open chrome://extensions/shortcuts and make sure Proofread the focused text field is set to Alt + Shift + L.
Install in Firefox
  1. Download the Firefox extension from the button above (or GitHub Releases).
  2. If you got a .zip, unzip it and keep the folder on disk.
  3. Open about:debugging → This Firefox.
  4. Click Load Temporary Add-on and pick the downloaded .xpi, or the manifest.json inside the unzipped folder.
  5. The add-on stays active until you close Firefox. The package is unsigned for now.
Known limits (beta)
  • Google Docs is not supported yet.
  • The Firefox package is unsigned and requires Firefox 142 or later. Temporary install only.
  • The desktop app must be running (it can stay in the system tray).
  • Packaged desktop builds enable operating-system startup by default and may check for updates in the background.
  • The status badge turns gray when the desktop app is unavailable.
  • Beta builds may be unstable. Report issues on Discord.

WHY LEXICON WAS BUILT

A quiet desk for your thoughts.

Writing is personal. Cloud writing tools turned document editors into monthly subscriptions, background telemetry, and remote server queues. We built Lexicon because we wanted a quiet, distraction-free desk on our own machine, where prose is polished locally by default, data stays private by default, and software never asks for a login.

Built for people who prefer not to send drafts to someone else’s server; configured endpoints remain your choice.

Zero First-Party Telemetry

No tracking scripts or in-app analytics. Built-in writing processing stays local; configured processing servers are opt-in. Updates and model downloads may use the network.

Lexicon Code (MIT)

Lexicon-authored code is MIT-licensed. Bundled dependencies and model weights have separate licenses.

No Subscription

No monthly fees, hidden paywalls, or trial limits. Built out of passion for independent software.

Privacy by Design

Your prose belongs to you

No Lexicon cloud storage, no first-party tracking, and no subscription fees. Lexicon runs locally by default, with network exceptions for downloads, updates, and servers you configure.

Local Profile Storage

LOCAL BY DEFAULT

Your drafts, personal dictionaries, custom settings, and local writing metrics are stored in your local user profile. No Lexicon cloud sync, mandatory account creation, or first-party background telemetry.

Embedded LanguageTool Engine

LOCAL BY DEFAULT

Grammar, spelling, and style rule passes run deterministically on your local CPU via the embedded runtime in packaged builds. A source or development user can configure a remote LanguageTool-compatible endpoint.

Local-First LLM Inference

LEX'S ENGINE

Lex, Lexicon's writing assistant, can use a downloaded local GGUF model (Light 0.8 GB or Standard 1.4 GB) on supported builds, or use your Ollama or LM Studio server. A network URL you configure may receive transform text and prompts; Windows x86 and ARM64 builds do not include the native GGUF engine.

Complete Data Ownership

OPEN STANDARDS

Import `.docx`, `.md`, `.txt`, and `.html` documents. Export to PDF, EPUB, styled HTML, or DOCX. Remove downloaded models in Settings and manage drafts, history, and dictionary entries in the app. A full local-data wipe may still require browser or operating-system controls; locked history and the current document are not removed by the history controls.

FAQ

Questions writers ask

Is Lexicon free to download and use?

Yes. Lexicon is MIT-licensed open source: no subscription, no account gate, and no trial that expires. Use it personally or commercially.

What operating systems can I install Lexicon on?

Windows (x64, ARM64, and x86), macOS (Apple Silicon and Intel), and Linux via .deb. Pick the matching build from the download button on this page.

Does Lexicon upload my writing to the cloud?

Not to a Lexicon-operated cloud service. Built-in proofreading and local AI can run on your machine; a remote endpoint you configure may receive the text sent to it. Lexicon has no accounts or first-party writing analytics.

Do I need a Lex model just to proofread?

No. Grammar and style checks work without an AI model. Download a local Light (~0.8 GB) or Standard (~1.4 GB) model on supported builds when you want Lex rewrites, or connect your own Ollama or LM Studio server. A configured network server may receive the text and prompt sent to it.

Can I proofread without an internet connection?

Yes. The packaged LanguageTool engine handles spelling, grammar, punctuation, and style locally when you run a check, so proofreading can work offline. A configured remote LanguageTool-compatible endpoint is an exception.

Is there a browser extension?

Yes. A beta browser extension for Chrome and Firefox proofreads multiple visible text fields, including supported frames, through the desktop app. It also offers Tone and rewrite actions from field badges. Google Docs is not supported yet, the Firefox package is unsigned (temporary install only), and the desktop app must be running. See the Extension section for downloads and install steps.

Why does Windows or macOS warn that Lexicon is unsigned or unsafe?

Desktop builds are not yet code-signed (Windows) or notarized (macOS). SmartScreen, Gatekeeper, and some antivirus tools warn on new or unsigned indie installers. That is a reputation / signing gap, not proof the file is malware. Only download from GitHub Releases, then follow the SmartScreen / Gatekeeper steps under Setup & Support.

Why use Lexicon instead of a cloud grammar checker?

Most cloud checkers bill monthly and process your documents on their servers. Lexicon is a free desktop writing app with offline grammar and local AI options. Updates, model downloads, and any server you configure are separate network paths.

Windows (SmartScreen & antivirus)

Windows builds are not yet Authenticode code-signed. SmartScreen often shows "Windows protected your PC" for new or unsigned indie installers. That is a reputation warning, not proof the file is malware. Only install builds from GitHub Releases.

SmartScreen:

  1. Click More info under the warning prompt.
  2. Click Run anyway to complete installation.

Antivirus (Defender, AVG, etc.): some tools may quarantine the installer or flag “malicious code” as a false positive on unsigned NSIS installers. Confirm the file came from the official Releases page and that the asset name matches the selected build, then restore or allow it in your AV quarantine settings.

macOS (Gatekeeper)

macOS builds are currently unsigned / not notarized. Gatekeeper may show "Lexicon cannot be opened because it is from an unidentified developer", or block the background engine. That is an unsigned-developer warning. Only download from GitHub Releases.

  • Option 1 (GUI): Control-click (right-click) Lexicon.app → select Open → click Open.
  • Option 2 (System Settings): Open System Settings > Privacy & Security → scroll down and click Open Anyway.
  • Option 3 (Terminal): Run xattr -cr /Applications/Lexicon.app in Terminal to clear the quarantine flag.
Linux (Debian / Ubuntu)

To install the .deb package on Ubuntu, Debian, Linux Mint, or Pop!_OS:

  1. Double-click the downloaded .deb file to install via Software Center.
  2. Or run sudo dpkg -i Lexicon_*.deb (or sudo apt install ./Lexicon_*.deb) in Terminal.
